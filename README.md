# Codeforces Solutions

This repository contains my solutions to programming problems from [Codeforces](https://codeforces.com/), implemented in Python.

It serves as a collection of solved problems and a record of my progress in competitive programming. Each solution focuses on understanding the problem, developing an approach, and implementing an efficient solution.

## Repository Structure

Each solution is stored in an individual Python file, named using the problem title and its Codeforces ID.

## Problem Solutions

| Problem Name | Problem ID | Solution File |
|---|---|---|
| Way Too Long Words | 71A | `way-too-long-words-71a.py` |
| Beautiful Matrix | 263A | `beautiful-matrix-263a.py` |
| Boy or Girl | 236A | `boy-or-girl-236a.py` |

## Language

- Python 3

## Purpose

- Practice competitive programming.
- Improve problem-solving and logical thinking.
- Explore different algorithms and approaches.
- Maintain a record of solved Codeforces problems.
